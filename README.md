# homebrew-tap

Homebrew tap for [twen](https://github.com/kannwism/twen), a minimal macOS
menu bar app for the 20-20-20 rule.

## Install

```sh
brew install kannwism/tap/twen
```

The cask's `version` and `sha256` are bumped automatically by twen's
[release workflow](https://github.com/kannwism/twen/blob/main/.github/workflows/release.yml)
whenever a `v*` tag is pushed.
